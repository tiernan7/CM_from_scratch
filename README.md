# CM_from_scratch
implementing a covariance model from scratch in Rust

Durbin/Eddy scaffold files are now split by chapter in:
- `/home/runner/work/CM_from_scratch/CM_from_scratch/chapter_examples/`

Chapter scaffold files:
- `chapter_examples/pairwise_alignment.rs` — Pairwise alignment
- `chapter_examples/markov_chains_and_hidden_markov_models.rs` — Markov chains and hidden Markov models
- `chapter_examples/pairwise_alignment_using_hmms.rs` — Pairwise alignment using HMMs
- `chapter_examples/profile_hmms_for_sequence_families.rs` — Profile HMMs for sequence families
- `chapter_examples/multiple_sequence_alignment_methods.rs` — Multiple sequence alignment methods
- `chapter_examples/building_phylogenetic_trees.rs` — Building phylogenetic trees
- `chapter_examples/appendix_proof_of_neighbour_joining_theorem.rs` — Appendix: proof of neighbour-joining theorem
- `chapter_examples/probabilistic_approaches_to_phylogeny.rs` — Probabilistic approaches to phylogeny
- `chapter_examples/transformational_grammars.rs` — Transformational grammars
- `chapter_examples/rna_structure_analysis.rs` — RNA structure analysis
- `chapter_examples/background_on_probability.rs` — Background on probability

Each file contains empty Rust function stubs for the topics in that chapter so examples can be added incrementally.
